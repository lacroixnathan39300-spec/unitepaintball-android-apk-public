# Costumes mobile v136

Bundle mobile extrait de la source v135. Il contient le soldat GLB, les 6 pièces GLB, les portraits et le catalogue des 13 costumes.

IMPORTANT : les 13 costumes ne sont pas 13 géométries différentes. Le moteur existant applique couleurs, matières et effets aux mêmes pièces 3D. L'application doit charger les droits depuis GET /api/avatar/soldier et enregistrer uniquement via POST /api/avatar/soldier. Ne jamais calculer les droits côté téléphone.

Les pièces sont mélangeables : casque/visière, haut, gilet/armure, pantalon, gants et bottes. Une pièce verrouillée peut être prévisualisée mais pas sauvegardée.
